# Image Editor

This application is implementation of WebAssembly built by Rust Language, Goal of this project is impelementation of WebAssembly in website development, also is for my final project in my college.

Features:
- Color transfer
- Sharpen Image
- Color Adjuster (Saturation, Temperature, Tint)
- Light Adjuster (Contrast and Exposure)

## Tech stack

For this application i had some technologies which,
1. WebAssembly
2. Rust Language
3. ReactJs

So basically this WebAssembly in this project is package in NPM, to built it using Rust Language than compile to WebAssembly using `wasm-pack`. I have write about how to built WebAssembly package in my post [Build WASM package with rust](https://porto.alfazh.dev/blog/built-wasm-package-with-rust).
