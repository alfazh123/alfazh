Assa'adah Campus Expo or ACE is anual event that held by IKBAL Qomaruddin (Ikatan Alumni Qomaruddin), This project is the first project that i handle by myself as FrontEnd Developer. Because this is the first project I've worked on alone, I've definitely encountered some problems, including using some of technology that i never used before. 

From this project I learned a lot about time management, how to handle projects, research on campuses, and how to convey information appropriately through the products I made.

## Features
Because this is not a big platform it just a website for event information so basically the feature is such as:
- Landing page 
- Rowndown event
- Campus Information

## Tech Stack
- NextJs
- TailwindCSS
- DaisyUI
- MDX
