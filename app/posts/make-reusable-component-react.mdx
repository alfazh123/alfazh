# Make Reusable Component React

as we sould know that reactJs had a concept of component based, so basically you can make your one component and reuse in different condition on term in some of page. 

for simple example we can use a card or button, some of that component had a color, text, funciton, behaviour when click and many more needs. From that needs we can create reuse component that we want to make, in React we make component by built a function that return HTML, in that function the needs of component we call parameter or *props*.

there is much reason why you should make reuse component in react, first you may need more time in first time built a component but it will save much your time for developing later, second you can reduce boilerplate so it easier to debug component, you had consisten in your component, and your code will be clean and structured.

as an example bellow this is a function that return Button component.

```javascript
export default function Button({
    text='Click',
    color='bg-amber-500',
    onclick,
}: {
    text: string,
    color: string,
    onclick: () => void,
}) {
    return (
			<div
				onClick={onclick}
				className={`${color} h-fit w-fit text-white px-3 py-1 rounded-md hover:scale-105 flex cursor-pointer`}>
				<span>{text}</span>
			</div>
		);
}
```

As you can see on that component had parameter text, color, and onclick function. To use *Button* component that has just been create, you can write in other page like code bellow.
```javascript
export default function Page() {
    return (
        {/* */}
        <Button text={'Click'} color={'bg-[#e17100]'} onclick={() => console.log('click button')} />
        <Button text={'Hi'} color={'bg-[#2996ff]'} onclick={() => console.log('Hi')} />
        <Button text={'Hello there'} color={'bg-[#ff2a55]'} onclick={() => console.log('Hello There')} />
        {/* */}
    )
}
```

From code above we will get return like this.

<div className="flex gap-4 max-w-4xl w-full mx-auto justify-center items-center mt-10">

    <Button text={'Hi'} color={'bg-[#2996ff]'} onclick={() => console.log('Hi')} />
    <Button text={'Hello there'} color={'bg-[#ff2a55]'} onclick={() => console.log('Hello There')} />

Same like other function you can make default value for your component so you can use that component by just write parameter that you want to change, for example you can make default color and text for button component, so you just call component like this.

```javascript
export default function Button({
    text='Click',
    color='bg-amber-500',
    onclick,
}: {
    text: string,
    color: string,
    onclick: () => void,
}) {
    {/* Rest of code */}
}
```

    <Button text={'Hi'} onclick={() => console.log('Hi')} />
    <Button text={'Hello there'} onclick={() => console.log('Hello There')} />
</div>

Button component is just simple example of implementation of reusable component, you can make more complex component like card, banner, list of item, and many more. One thing you sould keep when make reusable component is you need to make your component flexible and customizable in different condition.
