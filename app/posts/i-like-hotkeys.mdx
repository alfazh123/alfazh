So basically hotkeys is a keyboard shortcut, you can use single key or combination of key in your keyboard to run a program on your operating system or your application. As an example when you want to save something you may use `Ctrl` + `s` or using `Ctrl` + `z` to undo your mistake in your file or program that you just built, why i love hotkey is because i think is simple and fast thing to do when i want to do something.

In this application you can use hotkeys method for open Command pallete by clicking `[K]` in your keyboard, `[Shift + K]` to close Command pallete, you can switch light and dark theme of website by pressing `[N]` for **dark theme** and `[]` for **light theme**, then there is page piano in this website on that page you can play piano with number of keyboard. And how i can make that happen? so basically we can use JavaScript API or Web API with name KeyboardEvent in our application, so the way it work is by KeyboardEvent will record all your interaction with your keyboard and in the event listener build function that you want to do when you press a single or some of key in your keyboard, for example look code bellow.

```JavaScript
window.addEventListener("keydown", (e: KeyboardEvent) => {
    if (e.key === 'k') {
        handleOpenCommandPallete();
    }
})
```

That function is an exapmle for open command pallete by pressing `[K]` in your keyboard. And how when you want to use a combination keys, you can use the same method but in If statement you can add another key like bellow.

```JavaScript
window.addEventListener("keydown", (e: KeyboardEvent) => {
    if (e.key === 'k' && e.key === 'l') {
        {/* some of command */}
    }
})
```

If you want to use `Shift`, `Alt`, or `Ctrl` key it will be different that using numeric or alphabet key, either using `e.key === 'key'` you can using `e.shiftKey`, `e.ctrlKey`, and `e.altKey`. So the function will be like this.

```JavaScript
window.addEventListener("keydown", (e: KeyboardEvent) => {
    if (e.key === 'k' && e.shiftKey) {
        {/* some of command */}
    }
})
```

As an advice to using hotkeys in React you can make your own React Hooks so you can make your code more clean and easy to maintain, for example you can look to this [repository](https://github.com/alfazh123/alfazh/blob/main/app/hook/useKeyboard.tsx) and you can look how to properly make your own hook to this [documentation](https://react.dev/learn/reusing-logic-with-custom-hooks).

## Conclusion

So hotkeys basically is a shortcut to run a program in your system operation or your application, and you can build for your web application by using JavaScript API or Web API by calling a command in event listener `"keydown"` by using \
`(e.key === {alphabet || numeric})` or using `e.shift`, `e.ctrlKey` and `e.altKey`.
